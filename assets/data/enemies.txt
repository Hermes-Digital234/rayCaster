#   enemy <id> health=<n> damage=<n> armor=<n> texture=<png path> <display name>
#   attack <enemyId> [multiplier=<x>] [weight=<n>] <attack name>
# An attack deals the enemy's damage * multiplier (before the target's armor). Weights decide how often each
# attack is chosen. The first enemy in this file is the default used when a map names an enemy that does not exist.
