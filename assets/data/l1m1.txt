# Tile data for layer 1, map 1 (l1m1.png).
# Coordinates are pixel positions in the map image: x counts from the left, y from the top, both starting at 0.
#
# skip <x> <y> [from=<north|east|south|west|any>]
#   A magenta pixel. "from" is the side of the wall the player must stand on the FIRST time they go through.
#   Example: from=west means standing west of the wall and walking east.
#   Once someone has gone through from the right side, it works from both sides until the map is unloaded.
#   A magenta pixel with no line here works from both sides right away.
#
# event <x> <y> [chance=0-100] [once=0|1] <message|battle|ask> <text>
#   Something that can happen on a pink pixel. The player walks onto the tile freely and presses the interact
#   button to start it. Several lines for the same pixel are tried in order, and the first one whose chance
#   roll succeeds happens (if none does, the player finds nothing).
#     message <text>   a popup with the text
#     battle <enemyId> a battle with that enemy (the only id so far is: basic)
#     ask <question>   the question plus a menu; the answers are the option lines right below it
#
# option <label> => [chance=0-100] <message|battle|item|nothing> [text]
#   An answer to the ask event above it (max 4 different labels). Repeating a label adds another possible
#   outcome for that answer; they are tried in order and the first whose chance succeeds happens, so end
#   with one that has no chance (it always succeeds).
#     message <text>       a popup with the text
#     battle <enemyId>     a battle
#     item <count> [text]  gives items, then shows the text (a default one if you leave it out)
#     nothing              nothing happens

# The wall between the starting room and the east room. Only passable from the starting room (west) at first.
skip 8 2 from=west

# 40% of the time a battle starts, otherwise you hear something.
event 12 9 chance=40 battle basic
event 12 9 message You hear a faint whisper somewhere in the dark.

# A question with answers. Picking up the bag has a 25% chance of an ambush, otherwise you get the item.
# It can only happen once per map load.
event 4 11 once=1 ask You see a bag left behind by another adventurer. Pick it up?
option Pick it up => chance=25 battle basic
option Pick it up => item 1 Inside the bag you find a healing potion.
option Leave it => message You leave the bag where it lies.
option Check for traps first => message You find nothing suspicious. The bag looks safe to pick up.
